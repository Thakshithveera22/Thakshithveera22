## Featured projects

**[Neural Signal Intelligence Platform](https://github.com/Thakshithveera22/neural-signal-intelligence-platform)**
EEG seizure detection pipeline on the CHB-MIT dataset. It includes feature engineering, a Random Forest classifier with SHAP explanations, a FastAPI service, and a Streamlit dashboard with PDF reports.
`Python` `scikit-learn` `SHAP` `MNE` `FastAPI` `Streamlit`

**[Vision + Data Intelligence Chatbot](https://github.com/Thakshithveera22/vision-data-intelligence-chatbot)**
Runs YOLOv8 detection and OpenCV preprocessing on images and video, stores results in SQLite, and answers questions about them through a rule-based query router. Served with FastAPI and Streamlit, and packaged with Docker.
`Python` `YOLOv8` `OpenCV` `FastAPI` `Streamlit` `Docker`

**[Image Description Generator](https://github.com/Thakshithveera22/Image-Description-using-NLP)**
Streamlit app that sends an uploaded image to Google's Gemini vision API and returns a short description.
`Python` `Streamlit` `Gemini API`

**WineWise: Wine Quality Prediction** *(private repo)*
Flask REST API that serves a wine quality prediction model.
`Python` `Flask` `REST API` `Machine Learning`

**Smart Assistant for Gestational Diabetes** *(private repo, in progress)*
Machine learning application for risk prediction, with modular Python components and a Streamlit interface.
`Python` `Streamlit` `Machine Learning`
